# UGC NET CS Paper 2 - 10 Units Mix Test

### Q1. Unit 1 Discrete: Number of onto functions from {1,2,3,4} to {a,b}?
**Answer: B) 14**
Explanation: Formula = 2^4 - 2 = 16 - 2 = 14. (Total functions minus 2 functions that go to only one element)

### Q2. Unit 2 C Prog: Output? `printf("%d", 5+++3);`
**Answer: B) Error**
Explanation: Compiler parses as `5++ + 3`. `5` is not an l-value, so `5++` is invalid. Gives l-value error.

### Q3. Unit 3 COA: 4-stage pipeline, 100 tasks. Speedup vs non-pipeline?
**Answer: B) 3.88**
Explanation: Non-pipeline time = 4 * 100 = 400. Pipeline time = k + n -1 = 4+99 = 103. Speedup = 400/103 = 3.88
