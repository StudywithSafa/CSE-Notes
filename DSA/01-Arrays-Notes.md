# Arrays - Simple Explanation

### What is Array?
Same type data-va continuous memory la store pannurathu than Array.

Example: int marks[5] = {90, 80, 70, 60, 50}

### Why we need?
- Fast access - marks[0] nu direct-a edukkalam
- Easy loop - for loop la ellam data-vayum paakalam

### Time Complexity:
Access: O(1) - super fast
Search: O(n)
